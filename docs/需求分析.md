# 需求分析

> 第 1 题：医院门诊预约与智能导诊系统
> 姓名：张健维　学号：24070213

---

## 一、题目背景

大医院科室特别多，患者去挂号经常会遇到三个问题：

1. **不知道该挂哪个科** —— 患者只会说"我胸闷、心悸"，但不知道这属于心血管内科；
2. **热门科室号很难挂** —— 不知道哪个时段还有号，跑过去才发现约满了；
3. **医院太大不好找** —— 就诊楼有 6 层，不同科室在不同楼层，患者找不到诊室。

所以想做这样一个系统：患者输入自己哪里不舒服，系统推荐该挂哪个科；
还能看医生的排班、在线预约、拿到预约凭证；预约以后能查到从大门到诊室怎么走；
到了医院签到后能排队候诊；医生临时停诊了能自动通知患者。

## 二、功能需求

### 2.1 题目要求的功能

| 编号 | 功能 | 具体要做什么 |
|---|---|---|
| 1 | **智能导诊** | 患者输入症状描述，系统根据"症状—科室"的关联关系推荐科室，用**推荐列表**显示，要有科室名称和匹配度 |
| 2 | **医生查询** | 能按科室、职称、擅长领域查医生 |
| 3 | **在线预约** | 选医生和时段后挂号，系统要检查号源够不够，成功后给出**预约凭证**（预约时间、科室、医生等） |
| 4 | **预约管理** | 患者能看自己的预约记录，能取消 |
| 5 | **排班展示** | 用**日历**的形式显示医生的排班 |
| 6 | **路线查询** | 给患者提供就诊路线，能精确到"某科室的某个医生" |
| 7 | **数据从文件读** | 测试数据通过文本文件读入 |
| 8 | **图形界面** | 用图形界面显示科室列表、排班、预约界面等 |

### 2.2 扩展要求

| 编号 | 功能 | 怎么做的 |
|---|---|---|
| 1 | **候诊队列实时管理** | 患者到院后签到进入队列，能看排队进度；支持叫号、过号、完成就诊；老年人自动优先 |
| 2 | **医生停诊自动通知** | 医生临时停诊时，自动找出受影响的预约，帮患者退号并退号源，给每位患者发通知 |
| 3 | **患者评价** | 看完病可以给医生打 1~5 星，评价后医生评分会重新算，导诊推荐时用上这个评分 |
| 4 | **科室间转诊推荐** | 某科室号源紧张时，推荐症状相近、还有号的科室 |

### 2.3 自己要补充的管理功能

| 功能 | 说明 |
|---|---|
| 患者登录 | 输入患者编号登录，这样只能看自己的预约 |
| 数据检查 | 启动时检查文件在不在、排班和预约对不对得上，出错给出提示 |
| 操作提示 | 每次操作在底部提示条显示结果，比如"挂号成功""号已经满了" |

## 三、输入数据

数据放在 `data/` 目录下 8 个文本文件里，用 `|` 分隔，`#` 开头的是注释。

| 文件 | 内容 | 条数 |
|---|---|---|
| `department.txt` | 科室编号、名称、位置、楼层、简介、常见症状 | 12 |
| `doctor.txt` | 医生编号、姓名、科室、职称、擅长、挂号费、评分 | 36 |
| `schedule.txt` | 排班编号、医生、日期、时段、最多几个、已约几个、状态 | 264 |
| `patient.txt` | 患者编号、姓名、性别、年龄、手机、密码 | 10 |
| `appointment.txt` | 预约编号、患者、排班编号、序号、状态、时间 | 28 |
| `evaluation.txt` | 评价编号、患者、医生、评分、内容 | 20 |
| `symptom.txt` | 症状关键词、科室、关联强度 | 80 |
| `map.txt` | 平面图节点（N 开头）和边（L 开头） | 58 节点 62 边 |

> **科室 12 个（要求 ≥10）、医生 36 人（要求 ≥30），满足题目要求。**
>
> 日期字段写成 `TODAY`、`TODAY+1` 这种形式，程序启动时会自动换成真实的今天/明天，
> 这样测试数据不会因为放久了就过期。

## 四、输出结果

| 输出 | 形式 |
|---|---|
| 科室、医生列表 | 界面上分区显示，有名称、位置、职称、评分、挂号费、诊室 |
| 导诊结果 | 推荐列表：科室名 + 匹配度百分比 + 医生数 + 剩余号源 |
| 排班日历 | 7 天 × 上午/下午的格子，显示"剩余/总数"，绿色有余号、红色约满、灰色停诊 |
| 预约凭证 | 多行文字：预约号、患者、科室、医生、职称、日期、时段、序号、诊室、费用、状态 |
| 路线 | 左边平面图标出路线，右边是"1. 沿走廊走到门诊大厅（20米）"这样的文字说明 |
| 候诊信息 | 排队名单（名次、序号、姓名、是否老年优先、状态） |
| 通知 | 医生停诊的通知内容 |

## 五、运行环境

| 项目 | 内容 |
|---|---|
| 系统 | Windows 11 |
| 编译器 | TDM-GCC 10.3（g++） |
| 图形库 | EasyX 20240601 |
| 语言 | C++17，只用基础语法，没用 STL 和模板 |

编译命令（`build.bat` 里就是这个）：

```
g++ -std=c++17 -Wall -O2 -Isrc -finput-charset=UTF-8 -fexec-charset=GBK
    src\main.cpp src\data.cpp src\logic.cpp src\graph.cpp src\ui.cpp
    -o build\hospital.exe -leasyx -lgdi32 -lole32 -loleaut32 -lcomdlg32
```
